Welcome to another issue of Haskell Weekly!
[Haskell](https://www.haskell.org) is a safe, purely functional programming language with a fast, concurrent runtime.
This is a weekly summary of what's going on in its community.

## Featured

- [A curmudgeon tries a language server](https://entropicthoughts.com/curmudgeon-tries-language-server) by kqr
  > I’m envious of what Lisp programmers do. Lisp development typically happens by typing code directly into the repl to add, remove, and replace parts of the live, running system. I’m not a Lisp developer, so I won’t ever get that experience. I’ll stay envious. But I also realised I haven’t really tried to get closer to it. Maybe there are some improvements I can get even in my working language of Haskell.
  
- [Code-Reviewing My First Monad Implementation](https://reasonablypolymorphic.com/blog/reviewing-my-first-monad/) by Sandy Maguire
  > I’ve been wanting to get back into the habit of blogging, and thought a fun project would be to go back through my old code and review it as the programmer I am now. So let’s do that.
  
- [Code-Reviewing Again](https://reasonablypolymorphic.com/blog/reviewing-again/index.html) by Sandy Maguire
  > Last time, we took a stroll down memory lane to review some ancient code I wrote, and see what/how I’d do things differently now. That was fun, and I have a new banger for us today.

- [Episode 85 – Brent Yorgey](https://haskell.foundation/podcast/85/) by The Haskell Interlude
  > In today’s episode, we’re joined by Brent Yorgey, Associate Professor of Computer Science at Hendrix College and the creator, among other things, of the Diagrams vector graphics library and Swarm, a 2D programming and resource gathering game. We talk about teaching, domain specific languages, and competitive coding.

- [First release candidate for Stack 4.1.1](https://discourse.haskell.org/t/first-release-candidate-for-stack-4-1-1/14595) by Mike Pilgrem
  > We are allowing a much longer period than usual before releasing a final version. This is to increase the opportunity for people interested in Stack’s support for GHC’s Backpack module system for cross-package use to check it behaves as described in Stack’s documentation and as expected. If all goes well, Stack 4.1.1 will be released at the end of Q3 2026.
  
- [Haskell diagrams: Tessellations](https://mgarletmilani.com/blog/2026-06-03-tessellations/) by Marcelo Garlet Milani
  > What makes Escher’s tessellations so fascinating for me is that he managed to cover the plane using birds, fishes, horses or other animals, making an otherwise quite abstract drawing into something alive. Interestingly, making some form of tessellation is not hard, although it certainly takes an artistic mind to actually find meaningful shapes that fit together. So let’s reconstruct one of Escher’s works using Haskell!
